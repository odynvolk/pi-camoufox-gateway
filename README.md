# pi-camoufox-gateway

Give [pi](https://pi.dev) web search and page reading through a self-hosted
[Camoufox](https://camoufox.com) browser gateway. No API keys, no per-query cost,
and JavaScript-rendered pages come back readable.

This repo is the pi extension; the gateway runs separately and this code talks to it over HTTP.

## Install

```
pi install git:github.com/odynvolk/pi-camoufox-gateway
```

## Status

Active development happens on the `feat/*` branches. The tool reference and setup notes live in
the full README on `feat/camoufox-web-search-tools`.
